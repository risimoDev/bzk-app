# BZK App — аналитика проекта и развитие

12 октября 2026

## Итог

Проект — качественная основа: современный стек, аккуратная безопасность, единые соглашения и админка из 28 разделов, покрывающая весь цикл от лида до УПД. Слабое место — денежная модель: одни и те же суммы и статусы живут в нескольких таблицах и расходятся, поэтому цифрам бухгалтерии и аналитики пока нельзя доверять без проверки.

Рекомендация: сначала закрыть аудит (отдельный документ), затем переделать ядро «заказ → деньги → склад» и только потом наращивать функции. Из нового больше всего окупятся онлайн-оплата, заказ без регистрации, поиск по каталогу и планировщик с напоминаниями для сотрудников.

Основано на разборе исходников (коммит 0ebc7d2, около 53 тыс. строк TypeScript, 93 таблицы в схеме БД) и документации в репозитории; бизнес-метрики сайта не анализировались.

## Что сделано хорошо

Сильнее всего проект в дисциплине: правила записаны, соблюдаются и проверяются скриптами, а большинство известных ошибок старого PHP-сайта уже исправлено.

**Архитектура и код**

- Next.js 16 (App Router, серверные действия), Drizzle + PostgreSQL 17, TypeScript; `tsc --noEmit` и `eslint --max-warnings=0` проходят чисто.
- Чистая логика отделена от работы с БД (`x.ts` / `x-db.ts` + `server-only`): одна формула цены на карточку товара и сервер, функции проверяются скриптами без Next.
- Комментарии объясняют «почему», а не «что»; единые компоненты админки (`AdminPage`, `AdminPager`, `ConfirmButton`), общие классы полей, постраничные списки вместо тихого `.limit(N)`.
- 16 групп проверок `npm run check` (раскрой, сумма прописью, редиректы, права на документы, безопасность) и `verify-restore`.
- Подробная документация: README, DEPLOY, SECURITY, HANDOFF с перечнем «грабель».

**Безопасность**

- Проверка прав в каждом серверном действии и на каждой странице админки (не только в layout); владелец проверяется при доступе к заказам, файлам, обращениям и печатным формам.
- CSP с nonce и `strict-dynamic`, `frame-ancestors 'none'`, HSTS; цена заказа всегда считается на сервере.
- Токены сброса хранятся SHA-256, сравнение секретов постоянного времени; TOTP для сотрудников; блокировка и смена пароля отзывают сессию сразу.
- Rate limit в БД (переживает перезапуск), защита от подмены X-Forwarded-For, одинаковое время ответа при несуществующей почте.
- Файлы клиентов вне public, случайные имена, защита от path traversal, отдача как `attachment` + `nosniff`; HTML документов чистится sanitize-html.
- Telegram привязывается по подписанному коду из кабинета, а не по почте, как было раньше; вебхук без секрета в проде отклоняется.

**Бизнес-логика**

- Заказ, позиции, промокод и бухгалтерская карточка пишутся одной транзакцией; остаток склада меняется с блокировкой строки и запретом ухода в минус.
- Документы клиенту открывает менеджер (флаг `documents_visible`); УПД по форме 1137 со статусом 2 для УСН, счёт с QR по ГОСТ Р 56042, сумма прописью.
- Все старые адреса PHP-сайта перенаправляются (SEO не теряется), идемпотентный перенос данных, учёт подписей старых строк себестоимости (нет удвоения при пересчёте).
- История переносов срока с обязательной причиной, журнал аудита, журнал уведомлений с каналом и ошибкой.

**Для клиента и сотрудников**

- Витрина с ценами по тиражам и подсказкой про следующую ступень, JSON-LD (Product, LocalBusiness), карта сайта из БД, страницы ошибок.
- Кабинет показывает оба типа заказов, чат по заказу, приёмку макетов с комментарием, обращения, таймлайн заказа.
- Админка закрывает полный цикл: CRM → КП → заказ → производство → ОТК → склад и закупки → бухгалтерия → документы, плюс Точка и Telegram-бот; сводка «на сегодня» фильтруется по правам роли.

**Инфраструктура**

- Docker standalone-сборка от не-root пользователя, БД не опубликована наружу, Caddy с авто-TLS, файлы в отдельном томе.
- Ночные бэкапы БД и файлов с сроком хранения, скрипты установки сервера с ufw и fail2ban, часовой пояс компании в контейнере приложения.

## Новые функции: публичный сайт и кабинет

Самый большой эффект дадут те функции, что убирают трение перед заказом: оплата онлайн, заказ без регистрации и мгновенный расчёт цены. Сейчас для заказа нужна регистрация, а оплата идёт только по счёту после согласования с менеджером.

| Функция | Зачем | Трудоёмкость |
| --- | --- | --- |
| Онлайн-оплата: платёжная ссылка/СБП Точки или ЮKassa, вебхук с автозачётом платежа в заказ | Клиент платит сразу после согласования, бухгалтер не вносит платежи руками | Низкая для ссылки Точки, средняя для ЮKassa |
| Онлайн-калькуляторы для типовых изделий (баннер по м², наклейки, визитки) на базе уже готового раскроя и настроек ценообразования | Цена без звонка — главный повод для заявки; калькулятор уже есть в админке | Средняя |
| Заказ без регистрации: аккаунт создаётся автоматически, вход по ссылке из письма | Регистрация перед первым заказом — типичное место потери покупателя | Средняя |
| Загрузка макета прямо в оформлении заказа + автопроверка (размер, разрешение, вылеты, CMYK) и превью | Меньше переписки про «макет не годится», быстрее запуск в печать | Высокая |
| Поиск, фильтры и сортировка в каталоге; цена «от» по ступени тиража | Каталог растёт, а сейчас есть только фильтр по категории | Низкая |
| Повтор заказа в один клик и «мои шаблоны» (тираж + макет + характеристики) | B2B-клиенты заказывают одно и то же регулярно | Низкая |
| Доставка: расчёт в оформлении (СДЭК / Яндекс Доставка), трек-номер в кабинете, выбор самовывоза | Сейчас адрес — просто текст, стоимость доставки в итог не попадает | Средняя |

| Корпоративные аккаунты: несколько сотрудников клиента в одном кабинете, согласование заказа руководителем (таблица заявок уже есть) | Крупные клиенты работают командой | Высокая |
| Портфолио и кейсы по отраслям, статьи «как подготовить макет», лучшие отзывы на главной | Доверие и SEO-трафик по низкочастотным запросам | Низкая |

## Приоритеты

После исправлений из аудита (этапы 0–1 обязательны до любых новых функций) начинать с квадранта «Сделать сразу». Планировщик фоновых задач — общая основа для дайджеста, сверки оплат и рассылок, поэтому его стоит сделать первым.

Матрица «ценность × трудоёмкость»:

| | Небольшие усилия | Большие усилия |
| --- | --- | --- |
| **Высокая ценность** | **Сделать сразу:** оплата по ссылке Точки с автозачётом; утренний дайджест в Telegram; повтор заказа в один клик; поиск и фильтры каталога; глобальный поиск в админке; отчёты с экспортом в Excel | **Крупные проекты:** онлайн-калькуляторы на витрине; сверка банковской выписки; заказ без регистрации и с макетом; календарь загрузки производства; выгрузка в 1С и ЭДО |
| **Умеренная ценность** | **Попутно:** портфолио и кейсы для SEO; Метрика с целями и UTM в заказе; шаблоны ответов клиентам; импорт и индексация цен CSV; удаление аккаунта по 152-ФЗ | **Позже:** партии материалов и FIFO; оборудование и нормочасы; корпоративные аккаунты; мобильный режим цеха с QR; рассылки по сегментам |

Раскладка — экспертная оценка по коду и описанию бизнеса в репозитории; если доля предоплаты или объём типовых заказов с сайта малы, калькуляторы и онлайн-оплата спускаются ниже.
